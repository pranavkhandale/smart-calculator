# Smart Calculator (Scientific)

A Python scientific calculator with support for advanced mathematical operations.

## Features
- Basic Operations: Addition, Subtraction, Multiplication, Division
- Square Root
- Power
- Factorial
- GCD (Greatest Common Divisor)
- LCM (Least Common Multiple)
- Trigonometric Functions: Sin, Cos, Tan
- Logarithm (natural log)
- Exponential
- Ceiling and Floor
- Euler's Number (e)

- ## How to Run
1. Clone this repo:
git clone https://github.com/pranavkhandale/smart-calculator.git

2. Run the file:
python smart-calculator.py
